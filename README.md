# Assemble

## What is Assemble

Assemble are some simple functions written in low level for practicing optimization and low level coding.

You can get any you want and try to make the fastest version possible of it.

Each one contains a benchmark file, which safely and accurately measures accuracy and time taken for comparing.

In the result, found at README.md of every folder, you can find two benchmarks: one with no optimizations and another with compiler optimizations.
